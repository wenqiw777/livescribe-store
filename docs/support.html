Help and questions

Support without the runaround.

Start with the checks below. If the issue remains, open a GitHub issue without including meeting transcripts, API keys, or other sensitive information.

Captions

No transcript appears

Use the browser version of Zoom, Meet, or Teams. Turn on the platform's captions or live transcription, then confirm LiveScribe was started for this meeting.

Control

Stop transcription

Click End in the LiveScribe panel. Caption collection stops and the save screen opens while the meeting itself continues.

Deletion

Remove saved data

Delete individual sessions from the extension popup. Uninstalling LiveScribe removes its Chrome extension storage.

AI

Ask or Summarize is unavailable

Transcription works without AI. For Q&A and summaries, open LiveScribe settings and add your Anthropic or OpenAI API key.
